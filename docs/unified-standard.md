# Единый стандарт платформы VPN_commerce для N1X VPN

> **Приоритет:** этот документ синхронизирует локальную документацию `company_n1xVPN-landing_Native` с [общей документацией экосистемы VPN_commerce](../../docs/README.md). Все 4 лендинга имеют единое функциональное поведение и отличаются **только внешним видом (дизайном, палитрой, брендом)** и назначенной тарифной сеткой.

## Профиль N1X VPN по единому стандарту

- **Тарифная сетка:** **Сетка B** (общая с kuniVPN), основная валюта — **EUR (`€`)**:
  - `Trial` (Триал — 1 месяц) — `€1` · 5 устройств · Один раз для нового пользователя
  - `1 месяц` (Далее — 1 мес) — `€7` · 5 устройств · —
  - `3 месяца` — `€15` · 5 устройств · `€5` в месяц (справочно)
  - `12 месяцев` — `€55` · 5 устройств · `€4.58` в месяц (справочно)
- **Целевые языки (единые для всех 4 сайтов, 12 языков):** `en` (по умолчанию), `pl`, `uk`, `lt`, `tr`, `ro`, `de`, `sk`, `hr`, `sr`, `bg`, `hu` (см. [единый контракт i18n](../../docs/architecture/i18n.md)). *(Предыдущая задача FRONT-002 покрывает базовый механизм `i18n.js` + `locales.json`; словарь расширяется до 12 языков.)*
- **Целевой состав страниц и функций (единый для всех 4 сайтов):**
  1. Основной лендинг (`index.html` — 5 секций N1X VPN + Telegram-вишлист на PHP 8.4).
  2. Регистрация (`create-account.html`).
  3. Вход в аккаунт (`login.html`).
  4. Восстановление пароля (`forgot-password.html`).
  5. Личный кабинет (`account.html` — референс `account-page/06-account.png`).
  Подробнее — [единый состав страниц](../../docs/product/pages-and-flows.md).
- **Уникальное для бренда:** только тёмная тема, неоново-лаймовый знак `X`, дизайн-концепты `docs/assets/images/concept/`.

Для всех общих вопросов по архитектуре, Docker/PHP-боту, CI/CD и интеграции с админкой использовать [общую документацию VPN_commerce](../../docs/README.md).
